Este archivo README muestra la imagen llamada "prueba" que contiene un ejemplo de cómo definir varias clases en un solo archivo Java y las reglas sobre clases públicas y el nombre del archivo.

- Solo una clase puede ser pública por archivo.
- El nombre del archivo debe coincidir con la clase pública.
- Se pueden tener varias clases no públicas en el mismo archivo.

La imagen ilustra estos conceptos con ejemplos y comentarios en español.

# Categorizar los Objetos Principales de la Base de Datos (13/05/2026)

![categorize-the-main-database-objects](./bd/Categorize%20the%20Main%20Database%20Objects.png)

En esta sección se realiza un análisis detallado de los objetos de base de datos en Oracle. El script SQL proporciona una clasificación completa de los objetos que se pueden crear en un Sistema de Gestión de Bases de Datos Relacionales (RDBMS) Oracle.

**Contenido del análisis:**

- **Definición de Objetos de Base de Datos**: Explicación de qué son y su importancia en las aplicaciones de base de datos.

- **Clasificación de Objetos**: Se incluye una lista completa de más de 40 tipos de objetos como:
  - Tablas (almacenan datos)
  - Vistas (consultas guardadas)
  - Índices (aceleran búsquedas)
  - Restricciones (protegen integridad de datos)
  - Secuencias (generan números automáticos)
  - Usuarios (acceso a Oracle)
  - Roles (agrupan permisos)
  - Sinónimos (alias para objetos)

- **Ejemplo Práctico**: Se crea una tabla básica `work_schedule` con columnas para ID, fecha de inicio y fecha de finalización, demostrando la sintaxis SQL para la creación de tablas.

- **Relación con Esquemas**: Se analiza cómo los objetos se relacionan con los esquemas en una base de datos Oracle.

Esta práctica es fundamental para comprender la estructura y arquitectura de una base de datos relacional. La fecha de realización es 13/05/2026.
