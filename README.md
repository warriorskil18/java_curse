# Prueba

![prueba](./prueba.png)

Este archivo README muestra la imagen llamada "prueba" que contiene un ejemplo de cómo definir varias clases en un solo archivo Java y las reglas sobre clases públicas y el nombre del archivo.

- Solo una clase puede ser pública por archivo.
- El nombre del archivo debe coincidir con la clase pública.
- Se pueden tener varias clases no públicas en el mismo archivo.

La imagen ilustra estos conceptos con ejemplos y comentarios en español.
